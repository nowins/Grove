# Inter 4.1

Unmodified static TTF faces: Regular (400), Medium (500), SemiBold (600), Bold (700), from `extras/ttf` in the official [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), asset `Inter-4.1.zip`.

Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter). Distributed under the SIL Open Font License 1.1 in `OFL.txt` (the release's `LICENSE.txt`). The same source files are embedded as Avalonia resources and bundled by the offline Web editor; no font modification, system installation or runtime font download is required. Chinese falls back to Microsoft YaHei UI on Windows.
