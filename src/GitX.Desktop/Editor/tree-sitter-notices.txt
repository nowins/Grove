GitX ships Java, C#, Python, JavaScript/JSX, TypeScript and TSX grammar WASM files from @vscode/tree-sitter-wasm 0.3.1. The separately shipped web-tree-sitter runtime is version 0.25.10. Package licenses are included alongside this file.

The upstream package-lock for @vscode/tree-sitter-wasm v0.3.1 records Python 0.25.0, JavaScript 0.25.0 and TypeScript 0.23.2; TSX is built from the same TypeScript package. Provenance: https://github.com/microsoft/vscode-tree-sitter-wasm/blob/v0.3.1/package-lock.json and build/main.ts. The original installed WASM bytes are copied without rebuilding.
