# JetBrains Mono

Unmodified JetBrains Mono 2.304 Regular and Italic, copied from the local IntelliJ IDEA 2025.3.1 runtime fonts to match the user's reference. The embedded copyright is `Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono)` and the embedded license identifies SIL Open Font License 1.1.

Upstream: <https://github.com/JetBrains/JetBrainsMono>. The accompanying `OFL.txt` is the upstream license and is copied into the offline editor distribution. No system font installation or font modification is performed.

The Desktop project also embeds these same TTF files as Avalonia resources for native code previews and Git output. UI text uses the separate shared Inter assets under `Assets/Fonts/Inter`.
