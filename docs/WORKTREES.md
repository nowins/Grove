# 工作树删除（开发分支）

此改动尚未合并或进入 Preview 3。

在工作树工具页选中关联工作树，点击“删除…”。应用先检查目标，再显示完整目录、分支、提交及无法在应用内撤销的提示；默认焦点在取消。执行前再次检查，使用 Git 自身的 `worktree remove`，不传 `--force`。

保护范围：

- 当前工作树、主工作树、裸仓库、锁定、缺失或失效登记不可删除。
- 未提交、未跟踪和被忽略的文件均阻止删除，不提供强制覆盖入口。
- 子模块、进行中的 Git 操作、已知锁文件、skip-worktree 和 assume-unchanged 文件均阻止删除。
- 工作树根目录、登记目录及 `.git` 文件为符号链接或目录联接时拒绝删除。
- 确认后分支、提交、登记目录或本地状态发生变化，停止并要求重新检查。
- 只删除所选关联工作树，保留其分支与提交；不执行 prune、解锁、强制删除或应用自己的递归删除。

删除在主窗口的 Git 操作工具页显示输出，执行期间不因切换工具页取消写入。其他程序仍可能修改同一工作树；应用检查与 Git 写入无法对外部程序形成原子事务，请先关闭使用目标目录的程序。

自动化测试仅使用测试创建的临时仓库，覆盖主/当前工作树、独立 HEAD、关联来源、分支保留、本地文件、忽略文件、锁、过期确认、子模块和取消。Windows 本机完成编译及逻辑测试；原生确认窗口、键盘焦点与 macOS GUI 尚未实测。
