# 在线更新

此功能已合并到 main，尚未发布新的安装包；现有 Preview 3 安装包不包含它。

在“帮助 → 检查更新”或主窗口的“更新”工具页检查版本。工具页可隐藏，下载仍在应用后台继续；下载中、可用及已下载状态会显示在工具页标签上。

## 版本与下载

- 固定读取 `nowins/Grove` 的公开 GitHub Releases，不需要 GitHub CLI 或 GitHub 登录，不读取或发送 GitHub 令牌、Cookie。仓库未公开、限流及网络错误会明确报错，不作为“没有更新”。
- 按语义化版本比较，支持稳定及预览渠道，忽略草稿，不自动降级。安装包根据操作系统原生 x64/ARM64 架构选择，不按模拟进程架构选择。
- 默认关闭自动检查和自动后台下载。启用自动检查后，在应用启动及每 6 小时检查；启用后台下载后，发现严格更高版本便下载。手动重新下载当前版本用于重装，不会自动开始。
- 同时核对 GitHub 资产的 SHA-256 和 `SHA256SUMS.txt`。缺少摘要、缺少唯一匹配的架构安装包、重复校验项、大小不符或哈希失败均停止。
- 使用系统 TLS 验证，逐跳验证 HTTPS 重定向，仅允许指定 GitHub 资产域名。签名下载 URL 仅保存在请求内存中，不写入设置或日志。
- 下载写入本次唯一 `.part` 文件，验证后才原子移动到缓存。取消、正常关闭和失败清理本次临时文件；不会递归清理其他会话。异常退出可能留下旧临时文件，重试不会将其当作完整包。
- 已有缓存每次使用前重新验证；损坏缓存保留为 `.invalid-*`，重新下载。重新安装前再次校验，不信任上一次下载的成功状态。

## 安装边界

下载完成不会安装或退出 Grove。必须点击“安装…”并确认；正在写入 Git、编辑合并或批注时不能开始安装。取消安装保留已校验的缓存。

Windows 保留下载区域标记，检查系统 Authenticode 状态；签名无效或不受信任时阻止启动，未签名包明确提示，再由用户决定是否交给系统交互式安装程序。不会传入静默安装参数、提权或强杀应用。

macOS 保留下载隔离标记，验证 DMG 完整性及可见的镜像签名；无效签名阻止打开，未签名镜像明确提示。确认后只打开 DMG，用户自行退出应用并拖入 Applications 替换；不后台覆盖 `.app`、移除隔离标记或绕过 Gatekeeper。

哈希验证代表内容一致，不代表已验证 Grove 发布者身份。当前发布包缺少开发者签名/公证保证；镜像内应用的签名、公证和完整 GUI 使用情况不能由下载成功推断。

## 数据和验证

继续使用原 GitX 用户数据目录或 `GITX_DATA_DIR`。设置为 `update-settings.json`，只包含三个布尔选项；安装包位于其下的 `updates`，不写入仓库配置或凭据存储。

自动测试覆盖版本、通道、四种架构、分页、错误响应、重定向、无凭据请求、哈希、缓存、取消、并发、设置和旧布局兼容。Windows 全量回归 577/577 通过。公开发布后，使用实际更新客户端匿名检查四架构的 Preview 3，完成 Windows x64 安装包下载、取消与半成品清理、双重 SHA-256 校验及缓存复用，并验证下载区域标记和系统 Authenticode 返回未签名；未启动安装器。

按钮点击、安装确认与 Mac 上的隔离标记、DMG 验证和原生界面仍未实测。Mac 安装包可以公开下载，不等同于在线更新分支已通过 Mac GUI 验收。
