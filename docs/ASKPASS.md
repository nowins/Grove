# Askpass 的 Unix 短路径

此修复从 Preview 4 起提供；Preview 3 不包含它。

.NET 的 Unix 命名管道默认把相对管道名放在临时目录下，并添加 `CoreFxPipe_` 前缀。macOS 的临时目录较长时，完整 Unix domain socket 路径可能超过 104 字节。

Unix 平台改用 `/tmp/.grove-ap-<随机标识>/p` 的绝对路径，完整路径小于 104 个 UTF-8 字节。每次 Git 操作使用独立的随机目录，权限为 0700；仍要求同用户连接并验证独立 nonce。Windows 继续使用原命名管道，不更改已有认证环境变量或用户凭据设置。

销毁会取消正在等待连接、读取或 UI 凭据响应的服务，清空内存中的脱敏列表，只尝试非递归删除本会话的空目录。若目录中有意外文件，不清理这些文件或其他会话。

`PlatformProbe --askpass-probe <结果路径>` 覆盖长 TMPDIR 下原错误复现、短绝对路径、目录权限、错误 nonce、Unicode、生产客户端、会话隔离、取消、未完成提示的销毁和临时目录回收。它还用只监听 loopback 的临时 HTTP 服务与真实 Git 进行凭据往返；测试值固定且无实际权限，不访问远端仓库，不更改系统 Git 配置。

四平台 CI 执行同一探针。Mac 长路径证据只能来自原生 Mac 运行结果；Windows 通过不能替代该结果。此探针验证凭据通道与 Git 集成，不替代实际 GUI 的凭据输入窗口、SSH 服务端或完整 Pull 的人工验收。
