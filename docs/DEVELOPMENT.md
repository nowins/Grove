# 开发约定

Grove 当前是个人本地 Git 与代码查看器。核心在 src/GitX.Core，Avalonia 桌面壳在 src/GitX.Desktop，离线 Monaco／Tree-sitter 在 Editor 子目录，真实 Git 集成测试在 tests/GitX.Core.Tests。包版本和运行时图由项目及锁文件维护。

## 工作规则

- 保留工作区已有更改。生产 Git 读写分开；写入使用捕获上下文、重新校验和仓库写锁，不能用真实项目做破坏性测试样本。
- I/O、Git 和大 diff 运算离开 UI 线程；异步结果核对仓库、文件、修订和文档代次。取消读取不等于取消已经开始的 Git 写入。
- 测试 Git 写入使用随机专用临时仓库，检查真实 HEAD、索引、工作文件及其他 worktree。取消和拒绝操作不能伪装成功。
- UI 延续代码优先的深色统一工作区；复用字体、图标、颜色和组件状态。视觉建议与已实现行为分开记录。
- 内部 GitX 命名空间、Core 程序集、数据格式和缓存标识保持兼容；桌面 apphost/程序集使用 Grove。涉及持久化迁移时先识别数据、备份和验证范围。
- 未经任务授权不提交、推送、创建 PR、发布或启动并行代理工作。

## 验证与完成标准

构建与测试入口见 [CI](CI.md)。使用 npm ci 和 NuGet locked restore，不通过放开锁文件、减少历史上限或跳过失败测试制造通过。Editor 资源随源码构建和 publish，不提交 node_modules、dist 或 bin/obj。

按场景验证真实 Git 状态、旧结果失效、取消和错误处理。Windows／macOS 编译、自动化、原生 WebView／焦点／输入法、DPI 和长期性能分别报告；截图、Headless 或跨目标编译不能代替原生桌面验收。

完成说明包含行为变化、实际验证和剩余边界。当前验证范围见 [STATUS](STATUS.md)。

视觉精修按 [VISUAL-SPEC](VISUAL-SPEC.md) 分批实施；正文／元信息沿用现有字号，通过文字角色、字重和边线层级组织内容。原生与 Web 的辅助、禁用和焦点颜色保持对应；图文间距统一为 6，文件行和代码行高保持既有密度。截图与自动化结果分别记录，原始材料保留在忽略的 validation 或本机任务目录。

## 工具页与定位约束

Git 输出与任务共用一个工具页；隐藏或切换工具不取消 Git 写入。终止操作只作用于确认时捕获的任务与 PID。Worktree 列表异步结果按来源根目录和请求代次校验，打开前由 WorktreeCatalog 再读登记与目标共用目录；不得借界面改造清理或解锁工作树。

停靠枚举的新工具只追加数值，保留版本 1 布局及旧四工具 ID。项目筛选有内容时保持输入和清除入口可见；定位不能隐式清空条件。主编辑器与文件历史分别传递当前文档的仓库／路径，拒绝缺失或跨工作树目标，定位不重新读取或切换编辑器版本。原生与 WebView 的快捷键必须分别验收；WebView 的定位消息沿用当前已发布文档版本校验。

## 分支创建与检出

远端短名称按已配置 remote 的完整前缀提取，不假设第一个斜杠一定分隔 remote。跟踪匹配使用 canonical upstream，避免本地分支名与远端显示名相同时误选。多个跟踪分支优先当前或标准短名称，否则提示选择而不任意切换；已有分支的提交和配置不得重置或改绑。

New Branch 对字面 refs/heads 名称使用 Git 校验，不展开 @{-1}；默认提供未占用名称，写入前重新检查仓库快照。创建与创建后检出分开，脏工作树仅允许创建；不得使用强制覆盖或 ignore-other-worktrees。菜单的占用提示来自 worktree 目录，实际写入仍由 Git 做最终检查。输入框 Enter 不触发创建，保留输入法确认与显式按钮路径。

## Markdown 阅读

识别 `.md`、`.markdown`、`.mdown` 和 `.mkd`。单文件 Markdown 阅读默认显示预览，工具栏可切换到源码。预览与源码分别保留滚动位置；源码中的搜索或行定位会切回源码，预览中的 Esc 也返回源码。Diff 保持文本对比，不把渲染结果当作行级差异。

Marked 负责 GFM 解析，DOMPurify 使用明确的元素与属性白名单净化结果。原始 HTML 按文本显示，不接受样式、脚本、表单、SVG 或嵌入页面；代码块仅以等宽文本呈现。所有运行资源离线打包，并随包附带相应许可证。

图片只通过每窗口的随机 loopback 地址读取，绑定已发布文档的版本、仓库、路径与修订。仅支持 8 MiB 以内的仓库内 PNG、JPEG、GIF、WebP，拒绝符号链接、目录联接、Git 元数据、越界与无效路径。历史图片来自对应提交，当前 worktree 图片来自该 worktree。切换文档后旧版本地址失效。远程图片、SVG 与 data URI 不自动加载。

链接点击走校验版本的原生桥接：仓库内相对路径在当前文件目录解析，历史链接保留同一提交；缺失、超限或不安全目标不替换原文件。HTTP/HTTPS 网页仅在用户点击后交给系统浏览器，拒绝带凭据的 URL 与其他协议。当前不支持本地链接的查询参数、仓库根绝对路径、原始 HTML 锚点或 Markdown 扩展插件。

相关测试在 MarkdownTests 与 markdown-preview.test.js：覆盖渲染、注入与不安全协议、中文路径、重复标题锚点、切换/搜索、过期消息、图片格式/大小、历史及 worktree 隔离。Git 验证全部使用测试创建的临时仓库。


## 历史引用筛选与源码跳行

历史列表工具栏的分支筛选只改变历史查询范围，不调用 checkout。引用身份使用完整 canonical ref，显示名相同的本地分支、远端分支及标签不得合并。最近记录和收藏按工作目录分别保存；失效引用不再提供，选择前再次核对当前候选。搜索或方向键选中不能直接应用筛选，Enter 或显式点击才应用；星标和列表 Space 只改变收藏。

引用偏好写入使用本地原子替换，保留不支持版本或超限原文件。重建虚拟列表前将焦点留在弹层内，布局后仅在根目录、弹层代次、输入代次及搜索条件仍一致时恢复，防止移除焦点行导致下层 WebView 激活和弹层意外关闭。

源码 Ctrl+G 打开跳行输入；macOS 另提供 Command+L 原生菜单快捷键，同时保留 Ctrl+G。输入不移动光标，Enter 校验当前显示模型的真实行数，Esc 取消；空值、非整数或越界值原位提示，不静默截断。历史版本使用历史模型行数，Markdown 菜单定位先返回源码。打开表单时捕获文档代次、路径、模型及文本版本；切换文件、重新加载或关闭窗口后旧定位失效。原生菜单命令继续复用上下文检查，不能把编辑器中其他输入框的键盘操作当作源码跳行。

Mac CI 的 ChromeProbe 使用自身 AppKit 窗口队列发送 Command+L、Ctrl+G、Enter、Esc、方向键和 Space，检查实际 WKWebView/原生弹层的焦点与行为；输入框文本由测试设置，不冒充物理键盘输入或 IME 验收。探针只在生成的临时 Git 仓库和 linked worktree 中建立提交、引用与测试配置，并核对 HEAD、分支、索引及源文件未被导航操作改变。单个搜索结果按方向键时先进入当前结果，确保 Space 可收藏，不因越界而留在搜索框。

## 文件标签上下文菜单

普通文件、比较及历史源码标签的上下文菜单始终针对被点击的 tab ID，不因右键而切换文件。支持关闭标签、关闭其他、关闭全部；单标签时禁用关闭其他。Mac Control-click 不退化为左键选择或关闭按钮动作；Shift+F10/ContextMenu、方向键、Home/End、Enter/Space、Esc 可操作或取消。菜单复用现有浮层样式及视口定位；外部点击、滚动、失焦、载入或 tab 集合变化将取消旧菜单。

批量关闭在视图模型中一次确定保留集合，仅在活动标签实际被关闭时加载一次保留目标；保留活动标签时不发布新文档或重置视图。桥接及后端均核对文档版本和精确 ID，目标已消失时关闭全部也拒绝执行。清空文档必须在可空事件调用外递增读取代次，避免没有事件订阅者时旧读取恢复已关闭页面。

## 工作区文本编辑与系统位置（2026-11-04，本地）

仅普通 WorkingFile、当前工作树且严格 UTF-8 的可预览文件具有 Editing 元数据。基线绑定工作树根、路径、HEAD、原始字节 SHA-256、时间/长度/属性及 Unix mode；BOM 与均匀 LF/CRLF 单独保留。混合/单独 CR、无效编码、NUL、超过预览限制、只读或冲突状态不给予编辑许可。历史、差异、冲突与提示文档不因路径相同而获得保存权限。

浏览器按原生标签 ID 与工作树 RootKey 保留 Monaco 模型和撤销记录；刷新/删除/外部修改保留已有草稿，关闭后才释放模型。编辑器发送小型保存意图；原生端经仅字符串的 JSON 查询拉取捕获内容，重新验证标签、根与路径，再使用 WorkingTextWriter。保存回执针对捕获的模型/撤销检查点，保存期间新增输入仍为未保存。草稿内容与已发布快照不同时停用旧 Blame/评论行锚点，Markdown 预览使用草稿。草稿仅存在当前进程内存，不宣称崩溃恢复。

写入使用现有仓库写锁、严格 UTF-8 编码和同目录私有临时文件，落盘后原子替换并检查实际备份字节，拒绝陈旧基线、删除、链接或外部改写。失败保留内存草稿及可取得的原始/冲突/捕获草稿，恢复材料位于本工作树 Git 元数据的 grove-text-recovery；不自动暂存、提交或执行强制覆盖。关闭/换仓先冻结受影响模型，确认保存/放弃/取消，重新校验标签集合与仓库代次；保存或确认失败则保留当前上下文。

文件/文件夹系统位置先校验相对路径、存在性和工作树边界，拒绝 Git 元数据及链接/联接。Windows 用 Shell 项定位；终端使用固定可执行文件及 WorkingDirectory，不拼接 cd 或路径命令。macOS 用 open -R 和 Terminal.app 的参数列表。历史标签不映射到当前同名文件。外部程序在平台验收前只验证启动计划，不视为已通过 Finder/资源管理器/终端原生验收。

## 发布范围与文档就绪

Preview 5 功能批次保留原有完整 JSON 传输、序列化选项和评论快照算法；Lazy 载荷、Diff 省略 patch、长字符串 converter、原始 UTF-8 传输均留在独立本机实验中，不纳入此发布。

编辑器 loaded 只统计绑定到当前页面窗格的模型；缓存的非活动草稿和加载提示均不能宣布当前文档就绪。原生端仍核对文档版本及非提示文档，防止切换期间提前执行导航。
